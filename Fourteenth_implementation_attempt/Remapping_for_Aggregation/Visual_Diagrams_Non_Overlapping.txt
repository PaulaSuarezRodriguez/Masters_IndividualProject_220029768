DIAGRAM 3: THE SOLUTION - CLASSIFIER REMAPPING
================================================================================

Step 1: Identify Mappings
  Model 1 new_to_original: {0→12, 1→17, 2→23, 3→33, 4→37, 5→49}
  Model 2 new_to_original: {0→0, 1→47, 2→51, 3→52, 4→53, 5→54, 6→56, 7→57, 8→59}
  Model 3 new_to_original: {0→2, 1→11, 2→35}
  Model 4 new_to_original: {0→5, 1→8, 2→9, ..., 24→94}


Step 2: Remap Each Classifier
  
  Model 1 Original Classifier:     Model 1 After Remapping:
  ┌─────────────────────┐          ┌──────────────────────────────────────────────────┐
  │ [row 0] for class 0 │          │ Position 0:  zeros (not trained)                 │
  │ [row 1] for class 1 │          │ Position 1:  zeros (not trained)                 │
  │ [row 2] for class 2 │          │ ...                                              │
  │ [row 3] for class 3 │          │ Position 12: [copied from row 0]  ← class 12    │
  │ [row 4] for class 4 │          │ Position 13-16: zeros                            │
  │ [row 5] for class 5 │          │ Position 17: [copied from row 1]  ← class 17    │
  └─────────────────────┘          │ ...                                              │
  Size: [6, 512]                   │ Position 23: [copied from row 2]  ← class 23    │
                                   │ ...                                              │
                                   │ Position 49: [copied from row 5]  ← class 49    │
                                   │ ...                                              │
                                   │ Position 99: zeros (not trained)                 │
                                   └──────────────────────────────────────────────────┘
                                   Size: [100, 512]
  
  Result: Now row 12 = what Model 1 learned about class 12
          Row 17 = what Model 1 learned about class 17, etc.


  Similarly for Models 2, 3, 4:
  Model 2 remapped:  [100, 512] with rows 0, 47, 51, 52, 53, 54, 56, 57, 59 filled
  Model 3 remapped:  [100, 512] with rows 2, 11, 35 filled
  Model 4 remapped:  [100, 512] with rows 5, 8, 9, 10, ... 94 filled


Step 3: Aggregate (Combine Non-Overlapping Classes)
  
  Since classes don't overlap, each position in global classifier comes from AT MOST one model:
  
  Global Model Classifier (after aggregation):
  ┌──────────────────────────────────────────────────────────────────────┐
  │ Position 0:  from Model 2 (nature)           ← class 0               │
  │ Position 1:  zeros (not trained)                                     │
  │ Position 2:  from Model 3 (people)           ← class 2               │
  │ Position 3:  zeros (not trained)                                     │
  │ ...                                                                  │
  │ Position 5:  from Model 4 (objects/vehicles) ← class 5               │
  │ ...                                                                  │
  │ Position 12: from Model 1 (outdoors)         ← class 12              │
  │ ...                                                                  │
  │ Position 49: from Model 1 (outdoors)         ← class 49              │
  │ ...                                                                  │
  │ Position 100: zeros (not trained) [out of range]                     │
  └──────────────────────────────────────────────────────────────────────┘
  
  Size: [100, 512]  ← Now compatible with CIFAR-100!


Step 4: Use Global Model
  
  Input: Test image with CIFAR-100 label 12
         ↓
  Global model forward:
    Features extracted (512-dim)
         ↓
    Classifier matrix multiply: [512-dim] × [100, 512]ᵀ = [100-dim logits]
         ↓
    Prediction: argmax(logits) → predicted class
                (predicted class is 0-99, same space as input!)
         ↓
  ✓ CORRECT! No label space mismatch!

DIAGRAM 7: THE AGGREGATION IS SIMPLE!
================================================================================

Why? Because classes don't overlap!

Position 0 in global classifier:
  - Could come from Model 2? YES (maps 0→0)
  - Could come from Model 1? NO (doesn't train on class 0)
  - Could come from Model 3? NO (doesn't train on class 0)
  - Could come from Model 4? NO (doesn't train on class 0)
  
  Result: COPY weights from Model 2's position 0

Position 12 in global classifier:
  - Could come from Model 1? YES (maps 0→12)
  - Could come from Model 2? NO (doesn't train on class 12)
  - Could come from Model 3? NO (doesn't train on class 12)
  - Could come from Model 4? NO (doesn't train on class 12)
  
  Result: COPY weights from Model 1's position 0

Each position has exactly ONE source (or zero source if untrained)
→ No ambiguity!
→ No averaging needed!
→ Simple concatenation!
